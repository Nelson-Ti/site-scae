# SCAE 2.0

Landing page desenvolvida para o projeto SCAE.

## 🚀 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## ▶️ Como rodar o projeto localmente

Certifique-se de ter o **Node.js** instalado em sua máquina.

1. Clone este repositório:
   ```bash
   git clone https://github.com/Nelson-Ti/site-scae.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd site-scae
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o projeto:
   ```bash
   npm run start
   ```
